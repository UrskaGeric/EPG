Orodja 2: WSL – Linux na Windowsih

Kaj je WSL

WSL (Windows Subsystem for Linux) omogoča, da na Windows 10 ali 11 poganjamo pravo distribucijo Linuxa, npr. Ubuntu, brez virtualnega stroja in brez dvojnega zagona. WSL 2 ima pravo jedro Linux, zato v njem delujejo vsi linuxovi programi, tudi Docker (glej del 3).

Linux in Windows si delita datoteke: do map na Windowsih dostopate iz Linuxa in obratno.

PomembnoPotrebujete skrbniške pravice

Namestitev zahteva skrbniške pravice (administrator) in ponovni zagon računalnika. Na računalnikih z omejenimi pravicami (npr. v računalniških učilnicah) namestitev običajno ni mogoča.

Namestitev

Hitra pot (priporočeno)

  1. Odprite PowerShell kot skrbnik (desni klik na Start → Terminal (Admin) ali Windows PowerShell (Admin)).

  2. Vpišite:

    wsl --install

    Ukaz vklopi WSL in namesti Ubuntu.

  3. Ponovno zaženite računalnik.

Ročna pot (če hitra ne deluje)

  1. Nadzorna plošča → Programi → Programi in funkcije → Vklop ali izklop funkcij sistema Windows → obkljukajte Windows Subsystem for Linux (podsistem Windows za Linux).
  2. Ponovno zaženite računalnik.
  3. Odprite Microsoft Store, poiščite Ubuntu (izberite različico z oznako LTS) in kliknite Namesti.

Prvi zagon: uporabnik in geslo

Ko prvič odprete Ubuntu, vas vpraša za uporabniško ime in geslo za Linux. To je ločen uporabnik od vašega uporabnika na Windowsih.

  • Ime naj bo kratko, z malimi črkami in brez šumnikov (npr. urska).
  • Pri vpisu gesla se na zaslonu ne izpiše nič, niti zvezdice. To je normalno.
  • Geslo si zapomnite: potrebovali ga boste pri vsakem ukazu sudo.

Preverite, katero različico imate:

lsb_release -a

Nato posodobite sistem (to naredite občasno):

sudo apt update && sudo apt upgrade

Datoteke: Windows ↔︎ Linux

Iz Linuxa do map na Windowsih. Disk C: je v Linuxu viden kot /mnt/c:

cd /mnt/c/Users/VaseIme/Documents
ls

Iz Windows do domače mape v Linuxu. V Raziskovalcu (File Explorer) je v levem stolpcu spodaj mapa Linux. Lahko pa v naslovno vrstico vpišete:

\\wsl.localhost\Ubuntu\home\vaseime

Terminal v izbrani mapi. Odprite mapo v Raziskovalcu, v naslovno vrstico vpišite wsl in pritisnite Enter. Odpre se terminal Linux, ki je že v tej mapi.

NasvetKje naj bodo podatki

Linuxovi programi so precej hitrejši, če so podatki v domači mapi Linuxa (~), ne na /mnt/c. Za velike analize datoteke najprej kopirajte v Linux.

V domači mapi je skrita datoteka .bashrc. To je nastavitvena datoteka lupine: tu so barve terminala, poti do programov, nastavitve za condo ipd. Vidite jo z ls -a.

Pravice: sudo in root

V Linuxu ima navaden uporabnik dostop samo do svoje domače mape (/home/ime). Za nameščanje programov in spreminjanje sistema potrebujemo pravice skrbnika, ki se v Linuxu imenuje root.

  • sudo ukaz izvede en ukaz s pravicami root (vpraša za geslo). To je običajen način.
  • sudo -s odpre lupino kot root (poziv se spremeni v root@...#). Z exit se vrnete nazaj. Pazite: root ima svojo domačo mapo (/root), ki ni vaša.
sudo apt install htop     # namestitev programa
htop                      # poraba procesorja in pomnilnika; izhod s q

Koliko pomnilnika dobi Linux

WSL 2 privzeto dobi polovico pomnilnika računalnika. Če potrebujete več, v mapi C:\Users\VaseIme ustvarite datoteko .wslconfig:

[wsl2]
memory=12GB        # največ toliko RAM-a (prilagodite svojemu računalniku)
processors=4       # število jeder
swap=4GB

Nato v PowerShellu ponastavite WSL in odprite nov terminal Ubuntu:

wsl --shutdown

Z ukazom htop preverite, koliko pomnilnika zdaj vidi Linux.

OpozoriloNe dajte Linuxu vsega

Windows potrebuje svoj pomnilnik. Linuxu dodelite največ okoli 75 % pomnilnika računalnika.

Kako odpreti terminal WSL

  1. Aplikacija Ubuntu v meniju Start.
  2. Windows Terminal ali PowerShell: zavihek Ubuntu (puščica ob +) ali ukaz wsl.
  3. Raziskovalec: wsl v naslovni vrstici (odpre se v tej mapi).
  4. MobaXterm: WSL-Ubuntu v seznamu sej. Priročno, če imate hkrati odprte tudi povezave na strežnike, sicer pa porabi preveč pomnilnika.
  5. Visual Studio Code: razširitev WSL, nato Connect to WSL.
