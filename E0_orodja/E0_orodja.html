Orodja za bioinformatike: Linux, WSL in Docker

Priročnik o osnovnih računalniških orodjih za delo z genomskimi podatki ima tri dele: Linux v bioinformatiki, WSL: Linux na Windowsih in Docker: programi v zabojnikih. Vsi so neobvezni in namenjeni samostojnemu delu; za vaje jih ne potrebujete.

Linux v bioinformatiki

Vloga Linuxa v bioinformatiki

Linux je standardno okolje za analizo genomskih podatkov iz dveh razlogov.

Programska oprema. Večina bioinformatičnih programov je razvita za Linux in Unix. Programski cevovod (pipeline) od surovih odčitkov do datoteke VCF (npr. fastp, BWA, samtools, GATK, bcftools) in številni programi za populacijsko genomiko (npr. ADMIXTURE) delujejo samo v okolju Unix ali so tam najbolje podprti. Le redki programi, kot je PLINK, imajo tudi različico za Windows.

Strežniki in računska moč. Genomski podatki so obsežni (podatki celotnega genoma enega osebka obsegajo več deset GB), analize pa trajajo od nekaj ur do več dni. Zato tečejo na strežnikih in superračunalnikih (high-performance computing, HPC), ki imajo dovolj pomnilnika in procesorskih jeder ter lahko delajo neprekinjeno. Ti sistemi skoraj brez izjeme uporabljajo Linux.

Iz tega sledi način dela:

  • do strežnika dostopamo oddaljeno prek terminala (terminal) in ukazne vrstice (command line), brez grafičnega vmesnika;
  • posamezne korake analize povežemo v skripte (scripts), najpogosteje v jeziku Bash, ki jih lahko ponovimo na novih podatkih in tako zagotovimo ponovljivost analize.

Zgradba sistema Linux

Jedro (kernel)
Osrednji del operacijskega sistema. Posreduje med strojno opremo (procesor, pomnilnik, disk, mreža) in programi ter upravlja procese, pomnilnik, datotečni sistem in mrežo.
Distribucija (distribution, distro)
Celoten operacijski sistem, zgrajen okoli jedra Linux: jedro, sistemske knjižnice, orodja in upravitelj paketov. Najpogostejše so Ubuntu in Debian (osebni računalniki in strežniki) ter Rocky Linux in Red Hat Enterprise Linux (pogosti na superračunalnikih).
Lupina (shell)
Program, ki bere ukaze iz terminala in jih izvede. Najpogostejša lupina je Bash. 
+------------------------+
| programi               |  urejevalniki, R, PLINK, samtools ...
+------------------------+
| lupina (Bash)          |  vnos ukazov
+------------------------+
| sistemske knjižnice    |
+------------------------+
| jedro Linux            |  procesi, pomnilnik, datoteke, mreža
+------------------------+
| strojna oprema         |  procesor, RAM, disk
+------------------------+

Dostop do okolja Linux

Način Opis Primernost
Računalnik z Linuxom ali macOS terminal je vgrajen macOS ni Linux, je pa sistem Unix: večina ukazov je enakih
WSL (Windows Subsystem for Linux) polna distribucija Linuxa (npr. Ubuntu) znotraj Windows 10/11 priporočena izbira na Windowsih
Git Bash lupina Bash z osnovnimi ukazi na Windowsih preprosti ukazi; nameščen skupaj z Gitom

Povezava s strežnikom

Na strežnik se povežemo prek protokola SSH (Secure Shell), datoteke pa prenašamo prek SFTP (SSH File Transfer Protocol) ali z ukazom scp.

Program Namen Opomba
Terminal / PowerShell ssh ime@streznik vgrajeno v Windows 10/11, macOS in Linux
MobaXterm SSH in SFTP, več povezav v zavihkih, tudi WSL priročen, vendar porabi veliko pomnilnika
PuTTY SSH ena povezava naenkrat; povezave je mogoče uvoziti v MobaXterm
FileZilla, WinSCP prenos datotek (SFTP) WinSCP samo za Windows
Visual Studio Code (Remote – SSH) urejanje datotek neposredno na strežniku datotek ni treba hraniti lokalno 
# povezava na strežnik
ssh ime@streznik.primer.si

# kopiranje datoteke na strežnik in s strežnika
scp podatki.vcf ime@streznik.primer.si:/home/ime/projekt/
scp ime@streznik.primer.si:/home/ime/projekt/rezultat.txt .

Osnovni ukazi

Ukaz Pomen
pwd izpiše trenutno mapo
ls -lh izpiše vsebino mape z velikostmi datotek
cd mapa, cd .., cd ~ premik v mapo, eno raven višje, v domačo mapo
mkdir mapa ustvari mapo
cp vir cilj, mv vir cilj kopira, premakne ali preimenuje
rm datoteka izbriše datoteko (trajno, brez koša)

wc -l datoteka prešteje vrstice (npr. število SNP-jev v datoteki .bim)

Ukaze povezujemo s cevjo (pipe, |): izhod enega ukaza postane vhod naslednjega. Primer: število map z rezultati v trenutni mapi, brez podmap.

find . -maxdepth 1 -type d -name "*result*" | wc -l
  • . trenutna mapa
  • -maxdepth 1 brez iskanja po podmapah
  • -type d samo mape (-type f samo datoteke)
  • -name "*result*" ime vsebuje result
  • | wc -l prešteje vrstice izpisa

WSL: Linux na Windowsih

Kaj je WSL

WSL (Windows Subsystem for Linux) omogoča, da na Windows 10 ali 11 poganjamo pravo distribucijo Linuxa, npr. Ubuntu, brez virtualnega stroja in brez dvojnega zagona. WSL 2 ima pravo jedro Linux, zato v njem delujejo vsi linuxovi programi, tudi Docker (glej Docker: programi v zabojnikih).

Linux in Windows si delita datoteke: do map na Windowsih dostopate iz Linuxa in obratno.

PomembnoPotrebujete skrbniške pravice

Namestitev zahteva skrbniške pravice (administrator) in ponovni zagon računalnika. Na računalnikih z omejenimi pravicami (npr. v računalniških učilnicah) namestitev običajno ni mogoča.

Namestitev

Hitra pot (priporočeno)

  1. Odprite PowerShell kot skrbnik (desni klik na Start → Terminal (Admin) ali Windows PowerShell (Admin)).

  2. Vpišite:

    wsl --install

    Ukaz vklopi WSL in namesti Ubuntu.

  3. Ponovno zaženite računalnik.

Ročna pot (če hitra ne deluje)

  1. Nadzorna plošča → Programi → Programi in funkcije → Vklop ali izklop funkcij sistema Windows → obkljukajte Windows Subsystem for Linux (podsistem Windows za Linux).

  2. Ponovno zaženite računalnik.

  3. Odprite Microsoft Store, poiščite Ubuntu (izberite različico z oznako LTS) in kliknite Namesti.

Prvi zagon: uporabnik in geslo

Ko prvič odprete Ubuntu, vas vpraša za uporabniško ime in geslo za Linux. To je ločen uporabnik od vašega uporabnika na Windowsih.

  • Ime naj bo kratko, z malimi črkami in brez šumnikov (npr. urska).
  • Pri vpisu gesla se na zaslonu ne izpiše nič, niti zvezdice. To je normalno.
  • Geslo si zapomnite: potrebovali ga boste pri vsakem ukazu sudo.

Preverite, katero različico imate:

lsb_release -a

Nato posodobite sistem (to naredite občasno):

sudo apt update && sudo apt upgrade

Datoteke: Windows ↔︎ Linux

Iz Linuxa do map na Windowsih. Disk C: je v Linuxu viden kot /mnt/c:

cd /mnt/c/Users/VaseIme/Documents
ls

Iz Windows do domače mape v Linuxu. V Raziskovalcu (File Explorer) je v levem stolpcu spodaj mapa Linux. Lahko pa v naslovno vrstico vpišete:

\\wsl.localhost\Ubuntu\home\vaseime

Terminal v izbrani mapi. Odprite mapo v Raziskovalcu, v naslovno vrstico vpišite wsl in pritisnite Enter. Odpre se terminal Linux, ki je že v tej mapi.

NasvetKje naj bodo podatki

Linuxovi programi so precej hitrejši, če so podatki v domači mapi Linuxa (~), ne na /mnt/c. Za velike analize datoteke najprej kopirajte v Linux.

V domači mapi je skrita datoteka .bashrc. To je nastavitvena datoteka lupine: tu so barve terminala, poti do programov, nastavitve za condo ipd. Vidite jo z ls -a.

Pravice: sudo in root

V Linuxu ima navaden uporabnik dostop samo do svoje domače mape (/home/ime). Za nameščanje programov in spreminjanje sistema potrebujemo pravice skrbnika, ki se v Linuxu imenuje root.

  • sudo ukaz izvede en ukaz s pravicami root (vpraša za geslo). To je običajen način.
  • sudo -s odpre lupino kot root (poziv se spremeni v root@...#). Z exit se vrnete nazaj. Pazite: root ima svojo domačo mapo (/root), ki ni vaša.
sudo apt install htop     # namestitev programa
htop                      # poraba procesorja in pomnilnika; izhod s q

Koliko pomnilnika dobi Linux

WSL 2 privzeto dobi polovico pomnilnika računalnika. Če potrebujete več, v mapi C:\Users\VaseIme ustvarite datoteko .wslconfig:

[wsl2]
memory=12GB        # največ toliko RAM-a (prilagodite svojemu računalniku)
processors=4       # število jeder
swap=4GB

Nato v PowerShellu ponastavite WSL in odprite nov terminal Ubuntu:

wsl --shutdown

Nov terminal Ubuntu odprete s puščico ob + v oknu Terminal:

Z ukazom htop preverite, koliko pomnilnika zdaj vidi Linux.

OpozoriloNe dajte Linuxu vsega

Windows potrebuje svoj pomnilnik. Linuxu dodelite največ okoli 75 % pomnilnika računalnika.

Kako odpreti terminal WSL

  1. Aplikacija Ubuntu v meniju Start.

  2. Windows Terminal ali PowerShell: zavihek Ubuntu (puščica ob +) ali ukaz wsl.

  3. Raziskovalec: wsl v naslovni vrstici (odpre se v tej mapi).

  4. MobaXterm: WSL-Ubuntu v seznamu sej. Priročno, če imate hkrati odprte tudi povezave na strežnike, sicer pa porabi preveč pomnilnika.

  5. Visual Studio Code: razširitev WSL, nato Connect to WSL.

Docker: programi v zabojnikih

Zakaj Docker

Bioinformatični programi so pogosto zahtevni za namestitev: potrebujejo točno določene različice knjižnic, drug program jih potrebuje drugačne, na strežniku pa nimamo pravic za nameščanje. Rezultat analize je lahko odvisen tudi od različice programa.

Docker to reši tako, da program skupaj z vsem, kar potrebuje, zapakira v zabojnik (container). Zabojnik deluje enako na vašem prenosniku, na strežniku in pri sodelavcu. To je osnova ponovljivosti (reproducibility): čez dve leti lahko analizo ponovite s točno istimi različicami programov.

Slika (image)
Načrt oziroma »zamrznjen« paket: operacijski sistem, programi in nastavitve. Ne spreminja se.
Zabojnik (container)
Zagnana slika. Iz ene slike lahko zaženemo več zabojnikov.
Dockerfile
Recept (besedilna datoteka), iz katerega zgradimo sliko.
Docker Hub
Spletni repozitorij slik (podobno kot GitHub za kodo): https://hub.docker.com.

Zabojnik ni virtualni stroj: nima svojega jedra, ampak uporablja jedro gostitelja (Linux). Zato je majhen in se zažene v sekundi.

Namestitev

Windows in macOS: namestite Docker Desktop. Na Windowsih uporablja WSL 2 (glej WSL: Linux na Windowsih), zato najprej namestite WSL. V nastavitvah Docker Desktop (Settings → Resources → WSL integration) vklopite Ubuntu. Nato ukaz docker deluje tudi v terminalu Ubuntu.

Linux (ali WSL brez Docker Desktop):

sudo apt update
sudo apt install docker.io
sudo usermod -aG docker $USER   # da ne potrebujete sudo pred vsakim ukazom docker

Po zadnjem ukazu se odjavite in ponovno prijavite (v WSL: wsl --shutdown v PowerShellu).

Preizkus:

docker run hello-world

Če vidite pozdravno sporočilo, Docker deluje.

Osnovni ukazi

Ukaz Kaj naredi
docker pull ubuntu:24.04 prenese sliko z Docker Huba
docker images seznam slik na računalniku
docker run -it --rm ubuntu:24.04 bash zažene zabojnik in odpre lupino v njem; --rm ga po izhodu izbriše
docker ps, docker ps -a zagnani zabojniki, vsi zabojniki (tudi ustavljeni)
docker stop ime, docker rm ime ustavi, izbriše zabojnik
docker rmi slika izbriše sliko
docker logs ime izpis zabojnika
docker system prune počisti neuporabljene slike in zabojnike

Oznaka (tag) za dvopičjem je različica slike. Za ponovljivost vedno navedite točno različico (ubuntu:24.04), ne latest, ki se s časom spreminja.

Podatki v zabojniku

Zabojnik privzeto ne vidi vaših datotek. Mapo mu priklopimo (mount) z -v:

docker run --rm -v "$PWD":/data -w /data ubuntu:24.04 ls -lh
  • -v "$PWD":/data trenutno mapo pokaže v zabojniku kot /data
  • -w /data ukaz se izvede v tej mapi

Tako poganjamo bioinformatične programe: podatki ostanejo na vašem disku, program pa teče v zabojniku.

NasvetBioContainers

Za skoraj vsak bioinformatični program (samtools, bcftools, BWA, PLINK, ADMIXTURE …) že obstaja pripravljena slika v projektu BioContainers. Programa ni treba nameščati, samo prenesete sliko z ustrezno različico.

RStudio v zabojniku

Projekt Rocker pripravlja slike z R in RStudio Serverjem. Tako lahko imate točno določeno različico R, ne glede na to, kaj je nameščeno na računalniku:

docker run --rm -p 8787:8787 -e PASSWORD=izberi_geslo \
  -v "$PWD":/home/rstudio/projekt rocker/rstudio:4.4.0

V brskalniku odprite http://localhost:8787 (uporabnik rstudio, geslo, ki ste ga izbrali). Tako na strežnikih v raziskovalnih skupinah pogosto teče RStudio Server za več uporabnikov.

Lastna slika: Dockerfile

Preprost primer: program v Pythonu app.py

import math
print("sqrt of 16 is", math.sqrt(16))

in recept Dockerfile v isti mapi:

# osnovna slika: Python (točna različica)
FROM python:3.12-slim

# delovna mapa v zabojniku
WORKDIR /app

# kopiraj program v zabojnik
COPY app.py .

# ukaz, ki se izvede ob zagonu
CMD ["python", "app.py"]

Če program potrebuje dodatne pakete, jih naštejemo v requirements.txt in v Dockerfile dodamo COPY requirements.txt . in RUN pip install -r requirements.txt. Modul math je del Pythona, zato ga ni treba nameščati.

Zgradimo sliko in jo zaženemo (v mapi z Dockerfile):

docker build -t moj-program:1.0 .     # ime slike z malimi črkami; pika = ta mapa
docker run --rm moj-program:1.0       # izpiše: sqrt of 16 is 4.0

Deljenje slik: Docker Hub

docker login                                         # prijava z uporabniškim imenom in žetonom
docker tag moj-program:1.0 uporabnik/moj-program:1.0
docker push uporabnik/moj-program:1.0                # slika je zdaj javna
docker pull uporabnik/moj-program:1.0                # na drugem računalniku
OpozoriloGesla in žetoni ne sodijo v zapiske ali kodo

Za docker login uporabite dostopni žeton (access token), ki ga ustvarite na Docker Hubu, in ga hranite v upravitelju gesel. Gesel, žetonov in ključev API nikoli ne pišite v skripte, zapiske ali repozitorije: kdor jih najde, lahko dostopa do vaših računov. Če se to zgodi, žeton takoj prekličite in ustvarite novega.

Superračunalniki: Apptainer

Na superračunalnikih (HPC) Docker običajno ni dovoljen, ker zahteva pravice root. Namesto njega se uporablja Apptainer (prej Singularity), ki zna uporabiti iste slike Docker:

apptainer pull docker://ubuntu:24.04          # iz slike Docker naredi datoteko .sif
apptainer exec ubuntu_24.04.sif cat /etc/os-release

Zato se splača delo v zabojnikih naučiti že zdaj: isti program boste lahko pognali na prenosniku in na superračunalniku.
