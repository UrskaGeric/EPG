Orodja 1: Linux v bioinformatiki

Priročnik o osnovnih računalniških orodjih za delo z genomskimi podatki ima tri dele: Linux v bioinformatiki (ta stran), WSL: Linux na Windowsih in Docker: programi v zabojnikih.

Vloga Linuxa v bioinformatiki

Linux je standardno okolje za analizo genomskih podatkov iz dveh razlogov.

Programska oprema. Večina bioinformatičnih programov je razvita za Linux in Unix. Programski cevovod (pipeline) od surovih odčitkov do datoteke VCF (npr. fastp, BWA, samtools, GATK, bcftools) in številni programi za populacijsko genomiko (npr. ADMIXTURE) delujejo samo v okolju Unix ali so tam najbolje podprti. Le redki programi, kot je PLINK, imajo tudi različico za Windows.

Strežniki in računska moč. Genomski podatki so obsežni (podatki celotnega genoma enega osebka obsegajo več deset GB), analize pa trajajo od nekaj ur do več dni. Zato tečejo na strežnikih in superračunalnikih (high-performance computing, HPC), ki imajo dovolj pomnilnika in procesorskih jeder ter lahko delajo neprekinjeno. Ti sistemi skoraj brez izjeme uporabljajo Linux.

Iz tega sledi način dela:

  • do strežnika dostopamo oddaljeno prek terminala (terminal) in ukazne vrstice (command line), brez grafičnega vmesnika;
  • posamezne korake analize povežemo v skripte (scripts), najpogosteje v jeziku Bash, ki jih lahko ponovimo na novih podatkih in tako zagotovimo ponovljivost analize.

Zgradba sistema Linux

Jedro (kernel)
Osrednji del operacijskega sistema. Posreduje med strojno opremo (procesor, pomnilnik, disk, mreža) in programi ter upravlja procese, pomnilnik, datotečni sistem in mrežo.
Distribucija (distribution, distro)
Celoten operacijski sistem, zgrajen okoli jedra Linux: jedro, sistemske knjižnice, orodja in upravitelj paketov. Najpogostejše so Ubuntu in Debian (osebni računalniki in strežniki) ter Rocky Linux in Red Hat Enterprise Linux (pogosti na superračunalnikih).
Lupina (shell)
Program, ki bere ukaze iz terminala in jih izvede. Najpogostejša lupina je Bash.

| programi               |  urejevalniki, R, PLINK, samtools ...
+------------------------+
| lupina (Bash)          |  vnos ukazov
+------------------------+
| sistemske knjižnice    |
+------------------------+
| jedro Linux            |  procesi, pomnilnik, datoteke, mreža
+------------------------+

Dostop do okolja Linux

Način Opis Primernost
Računalnik z Linuxom ali macOS terminal je vgrajen macOS ni Linux, je pa sistem Unix: večina ukazov je enakih
WSL (Windows Subsystem for Linux) polna distribucija Linuxa (npr. Ubuntu) znotraj Windows 10/11 priporočena izbira na Windowsih
Git Bash lupina Bash z osnovnimi ukazi na Windowsih preprosti ukazi; nameščen skupaj z Gitom
Virtualni stroj (virtual machine, npr. VirtualBox) celoten sistem Linux v ločenem oknu porabi veliko pomnilnika, namestitev je zahtevnejša
Dvojni zagon (dual boot) Linux nameščen poleg Windows polna zmogljivost, vendar zahteva ponovni zagon ob vsakem preklopu
Oddaljeni strežnik (SSH) delo na oddaljenem računalniku z Linuxom običajen način za obsežne analize
Docker posamezni programi v zabojnikih ponovljivost, programi brez namestitve

Povezava s strežnikom

Na strežnik se povežemo prek protokola SSH (Secure Shell), datoteke pa prenašamo prek SFTP (SSH File Transfer Protocol) ali z ukazom scp.

Program Namen Opomba
Terminal / PowerShell ssh ime@streznik vgrajeno v Windows 10/11, macOS in Linux
MobaXterm SSH in SFTP, več povezav v zavihkih, tudi WSL priročen, vendar porabi veliko pomnilnika
PuTTY SSH ena povezava naenkrat; povezave je mogoče uvoziti v MobaXterm
FileZilla, WinSCP prenos datotek (SFTP) WinSCP samo za Windows
Visual Studio Code (Remote – SSH) urejanje datotek neposredno na strežniku datotek ni treba hraniti lokalno 
# povezava na strežnik
ssh ime@streznik.primer.si

# kopiranje datoteke na strežnik in s strežnika
scp podatki.vcf ime@streznik.primer.si:/home/ime/projekt/
scp ime@streznik.primer.si:/home/ime/projekt/rezultat.txt .

Osnovni ukazi

Ukaz Pomen
pwd izpiše trenutno mapo
ls -lh izpiše vsebino mape z velikostmi datotek
cd mapa, cd .., cd ~ premik v mapo, eno raven višje, v domačo mapo
mkdir mapa ustvari mapo
cp vir cilj, mv vir cilj kopira, premakne ali preimenuje
rm datoteka izbriše datoteko (trajno, brez koša)
head, tail, less prikaže začetek, konec ali celotno datoteko
wc -l datoteka prešteje vrstice (npr. število SNP-jev v datoteki .bim)
grep vzorec datoteka poišče vrstice, ki vsebujejo vzorec
find . -name "*.vcf" poišče datoteke po imenu
htop prikaže porabo procesorja in pomnilnika

Ukaze povezujemo s cevjo (pipe, |): izhod enega ukaza postane vhod naslednjega. Primer: število map z rezultati v trenutni mapi, brez podmap.

find . -maxdepth 1 -type d -name "*result*" | wc -l
  • . trenutna mapa
  • -maxdepth 1 brez iskanja po podmapah
  • -type d samo mape (-type f samo datoteke)
  • -name "*result*" ime vsebuje result
  • | wc -l prešteje vrstice izpisa
